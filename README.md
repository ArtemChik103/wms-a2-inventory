# WMS А2 — Экран «Товары на складе»

Веб-интерфейс раздела «Товары на складе» для системы складского учета **WMS А2**.

---

## Видеодемонстрация работы интерфейса

https://github.com/user-attachments/assets/demo.webm

> [Смотреть видеозапись демонстрации (`demo.webm`)](./demo.webm)
> 
> В видео продемонстрированы: живой поиск, фильтрация по статусам, сортировка колонок, открытие карточки товара, смена статуса в реальном времени и добавление нового SKU.

---


## Реализованный функционал

### 1. Верхняя панель (Header)
- Название системы: **WMS А2** (версия `v2.4`, статус синхронизации).
- Текущий раздел: **Товары** (активный индикатор с бейджем общего количества позиций).
- Профиль оператора и статус складского терминала.

### 2. Поиск и фильтрация
- Поле поиска по товару, артикулу (SKU), категории или номеру ячейки.
- Горячая клавиша `/` для быстрой фокусировки на строке поиска.
- Фильтр по статусу товара:
  - *Все статусы*
  - *Готов к отгрузке*
  - *На хранении*
  - *На сборке*
  - *Списан*
- Сброс фильтров в один клик.

### 3. Таблица товаров
- Отображение позиций номенклатуры (включая обязательные по ТЗ `WB-001` — `WB-004` и дополнительные позиции):
  - **SKU** — моноширинный код с быстрым копированием в буфер обмена.
  - **Товар** — наименование, товарная категория, текущее количество.
  - **Ячейка** — код адресного хранения на складе (например, `A-14-02`, `B-03-01`).
  - **Статус** — контрастные цветовые плашки со значками состояния.
  - **Действия** — кнопка «Открыть».
- Сортировка по колонкам (SKU, наименование, ячейка, статус, количество).
- Информативное состояние «Ничего не найдено» при пустой выборке.

### 4. Карточка товара (модальное окно)
- Открытие по кнопке «Открыть» или клику на строку.
- Просмотр подробных данных:
  - Штрихкод EAN-13 с функцией копирования.
  - Разбор структуры адреса хранения: Зона, Стеллаж, Ячейка/Полка.
  - Остаток в ячейке, единицы измерения, масса.
  - Описание и история складских операций (приемка, перемещение, сборка).
- Интерактивная смена статуса в реальном времени с обновлением в таблице.
- Имитация печати этикетки со штрихкодом.
- Закрытие по клавише `Escape`, кнопке закрытия или клику на оверлей.

### 5. Сводка склада (KPI Bar)
- Верхние метрические карточки с количеством позиций по каждому статусу.
- Интерактивная фильтрация таблицы по клику на карточку статуса.

## Стек технологий

- **Фреймворк**: React 19, TypeScript
- **Сборщик**: Vite 8
- **Стилизация**: Tailwind CSS v4
- **Иконки**: Lucide React
- **Хранение состояния**: Локальное состояние React + LocalStorage для сохранения изменений

---

## Запуск проекта

### Локальная разработка
```bash
npm install
npm run dev
```
Приложение откроется по адресу `http://localhost:5173`.

### Сборка для продакшена
```bash
npm run build
npm run preview
```
Скомпилированные статические файлы сохраняются в директорию `dist/`.
